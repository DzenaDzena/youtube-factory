# FS-002 visuals — паспорт папки (читать первым, особенно если вы — другой чат)

Проект: поиск изображений для ролика **FS-002 "10 Royal Jewels Elizabeth II Inherited — and the Women Who Wore Them First"** (YouTube, английский, монетизация).
Задание целиком: `BRIEF_FS-002.md` (175 кадров с таймкодами и фразой диктора, правила прав). **Правила прав из задания обязательны**: допустимы только PD / CC0 / CC BY(-SA, условия записать) / лицензия с доказательством; NC/ND, Getty/Alamy/AP/PA/Reuters, Royal Collection Trust, портрет Beaton 1953 — нельзя; сомнительное — `VERIFY` или `NOT FOUND`, а не подставлять.

Язык общения с владельцем: русский. Назначение результата: Obsidian `04 — Production/Ролики/FS-002 — elizabeth-ii-inherited-jewels/09 — VISUALS/`.

## Что в папке

| Что | Назначение |
|---|---|
| `MANIFEST.csv` | **Источник истины.** Одна строка = один кандидат (или NOT FOUND / кроп). Всё остальное вторично. |
| `SHOTS_INDEX.csv` | **Сводка «кадр → файлы»**: одна строка на каждый из 175 кадров (таймкод, фраза диктора, что нужно, основной и запасные файлы, статус, пометка). Состояние `state`: `HAS_FILE` / `CROP_TO_MAKE` / `NOT_FOUND`. Пересобирается `python3 tools/shots_index.py` из `MANIFEST.csv` и `BRIEF_FS-002.md`. Удобнее всего для монтажа и для нового чата. |
| `REPORT.md` | Автосводка по манифесту (генерируется `tools/report.py`): сколько найдено, что докачать, что проверить, NOT FOUND с зацепками. |
| `VIDEO_LEADS.md` | Видеоисточники: что нарезано, что отклонено и почему, что не проверено. |
| `proof/<Shot>_<rank>__proof.html` | Доказательство лицензии для файла: сохранённая страница Commons / LOC / запись Met, Cleveland API / метаданные archive.org. |
| `fetch_pending.py` | **Запускает человек у себя на компьютере**: докачивает картинки, которых нет в папке (через системный `curl`). См. ниже. |
| `tools/` | Рабочие скрипты поиска и скачивания (запускались в облачной сессии). Пути внутри заточены под ту среду — править `ROOT`. |
| `BRIEF_FS-002.md` | Копия задания. |
| Картинки и клипы | `<Shot>_<rank>__<slug>.<ext>`, лежат плоско в этой же папке. |

## Как читать имена и колонки

Имя файла: `S017A_main__elizabeth-sapphire-brooch-fco-2012.jpg` = кадр `S017A`, ранг `main`.

`rank`:
- `main` — основной вариант кадра; `alt1`, `alt2` — запасные.
- `alt3` — только у S057A: лишний видеовариант сверх схемы задания.
- `pool` — **не привязан к кадру**: общий пул для перебивок (музейные украшения, виды Лондона, портреты эпохи). Кадр = `POOL-J..` (украшения), `POOL-P..` (места), `POOL-L..` (LOC), `POOL-R..` (принты).

`status` (только эти): `PUBLIC_DOMAIN_VERIFIED`, `CC0_VERIFIED`, `CC_BY_VERIFIED` (включая CC BY-SA — условия в `licence`/`verify_note`), `VERIFY` (решает человек, причина в `verify_note`), `NOT FOUND` (в `verify_note` причина и лучшие зацепки).

`media`: `image` или `video`. Для видео в `verify_note` написано `in HH:MM:SS / out HH:MM:SS` исходника.

Особые строки:
- `title` начинается с `DERIVED CROP / COMPOSITE` — кадр делается кропом/композитом из файлов, уже лежащих в манифесте (в `verify_note` указано из какого). **Кроп ещё не вырезан.** Пустой `file` и `direct_file_url`.
- `status = NOT FOUND` — подходящей картинки с чистыми правами не нашли.

Ключевые слова в `verify_note`:
- `CHECKED VISUALLY` — я смотрел картинку глазами (возможно только для скачанных файлов).
- `JEWEL VERIFY` — это `[JEWEL]`-кадр: драгоценность на фото **не подтверждена**, сверить с описанием из задания.
- `VERIFY RIGHTS` — основание лицензии неочевидно, решение за владельцем.
- `VERIFY MEANING` — права в порядке, но смысл не точный (например, изделие Garrard вместо снимка лавки).
- `proof = Met API record` — страницы metmuseum.org из облака недоступны, доказательство = запись Open Access API (`isPublicDomain: true`).

## Правило для монтажа (важно)

- **Не удалять файлы из этой папки.** Это архив всего найденного: `fetch_pending.py` докачает любой удалённый файл заново, а `MANIFEST.csv`/`proof/` перестанут совпадать с содержимым.
- Для сборки ролика **копировать** выбранное в соседнюю папку `selected/` (по одному файлу на кадр: `main`, а если он не подошёл на монтаже — `alt1`/`alt2`).
- Вместе с каждым выбранным файлом сохранять его `proof/<Shot>_<rank>__proof.html` и строку из `MANIFEST.csv` (на случай претензии Content ID или вопросов о правах).
- Для файлов `CC_BY_VERIFIED` (в том числе CC BY-SA) в описании ролика указать автора и лицензию: колонка `required_credit` и `licence`.
- Строки со статусом `VERIFY` и файлы с пометками `VERIFY RIGHTS` / `JEWEL VERIFY` в ролик не брать, пока человек не принял решение.

## Как продолжать работу

1. Прочитайте `REPORT.md` — там актуальные цифры и списки.
2. Новые кандидаты добавляйте в `MANIFEST.csv` (скрипты `tools/*.py` делают это сами: `fs.py get`, `met.py`, `loc.py`, `ia.py`, `cleveland.py`, `video.py`). После правок `python3 tools/report.py` пересобирает отчёт.
3. Источники по порядку удобства: Met Open Access, Cleveland (CC0), LOC (Bain, `No known restrictions`; для пула брали JPEG через `LOC_JPG=1`), archive.org (страницы книг `.../download/<id>/page/n<leaf>.jpg`, статус по `possible-copyright-status`), потом Commons.
4. Не повторять один файл на разные кадры (кроп одной картины на разные детали допустим, помечать).
5. Нельзя «чистить» кропом/ретушью/AI несвободный файл; AI-апскейл не используем (в Commons есть `...-TopazAI.jpg` — **не брали**).

## Известные проблемы и уроки

- **Wikimedia Commons блокирует скачивание картинок из облачной среды** (`upload.wikimedia.org` → HTTP 429, `Retry-After: 600`), поэтому картинки с Commons не скачаны в облаке: в манифесте есть лицензия, автор, `direct_file_url` и `proof`, а файл докачивает человек: `python3 fetch_pending.py` внутри папки (у владельца Mac, ~100 файлов, около 1–2 часов из-за пауз Wikimedia; прерывание безопасно, повторный запуск продолжает).
- API Commons тоже ограничивает частоту; `fs.py` держит паузу 4 с и прекращает работу при `Retry-After ≥ 300`.
- `fetch_pending.py` использует системный `curl` (на Mac у владельца Python даёт `CERTIFICATE_VERIFY_FAILED: self-signed certificate in chain` — перехват HTTPS). Видео-строки он пропускает: клипы нарезаны локально из источника.
- Папку нельзя держать в iCloud Drive (у владельца iCloud заполнен): держать в «Загрузках».
- Видео — SD (640×480), старая хроника; для 1080p годится только как вставка. Клип Kinemacolor 1912 содержит вшитый логотип Cineteca Bologna.
- Для `[JEWEL]`-кадров, чьи файлы не скачаны, сверка драгоценности глазами **не делалась** — сделать после докачки. Особенно: Diana 1985 (Lover's Knot не подтверждён), Queen Mary в кокошнике/Lover's Knot/Fringe, Durbar-тиара, Vladimir в LAC 1959.
- Решения владельца ожидают: `S207A` (St Paul's Survives — права неочевидны), `S250A` (официальный свадебный портрет 1947), `S058A` (Flickr Commons «No known restrictions»), `S068A` (книга 1863 без статуса в archive.org).
